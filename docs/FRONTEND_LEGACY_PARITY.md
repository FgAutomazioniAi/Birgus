# Frontend Storico: Parita con Backend Nuovo

## Completato
- Auth compatibile cookie `vl_session` (`login`, `logout`, `session`).
- Fallback workspace automatico quando `x-workspace-id` manca.
- Password recovery API:
  - `POST /api/auth/password/forgot`
  - `POST /api/auth/password/reset`
- Clienti:
  - `GET /api/clients`
  - `POST /api/clients`
  - `GET /api/clients/:clientId`
  - `PATCH /api/clients/:clientId`
  - `DELETE /api/clients/:clientId`
- Preferenze utente:
  - `GET /api/user/preferences`
  - `PATCH /api/user/preferences`
  - payload compatibile (`paletteId`, `righeProgetti`, `colonneProgetti`, ecc.).
- Progetti (shape compatibile UI legacy):
  - `GET /api/projects`
  - `POST /api/projects`
  - `GET /api/projects/:projectId`
  - `PATCH /api/projects/:projectId`
  - `DELETE /api/projects/:projectId`
  - `GET /api/projects/:projectId/versions`
  - `POST /api/projects/:projectId/versions`
  - `PATCH /api/projects/:projectId/versions`
  - `DELETE /api/projects/:projectId/versions`
- Notifiche compatibili topbar legacy:
  - `GET /api/notifications` (array)
  - `PATCH /api/notifications`
  - `DELETE /api/notifications`
- Endpoint file progetto legacy:
  - `/api/projects/:id/files/:kind`
  - `/api/projects/:id/files/:kind/content`
  - upload multipart compatibile form storico
- Endpoint preventivo legacy:
  - `/api/projects/:id/quotation`
  - `/api/projects/:id/quotation/file`
  - `/api/projects/:id/quotation/analyze`
- Endpoint orchestrator compat:
  - `/api/orchestrator/jobs/:jobId`
- Endpoint DDT reader legacy:
  - `/api/ddt-reader/config`
  - `/api/ddt-reader/documents*`
- Integrazione esecutiva del frontend storico (Next) dentro il nuovo workspace Birgus.

## Note operative
- Frontend storico integrato in `/frontend` con rewrite `/api/*` verso backend Fastify.
- Le route API Next legacy sono state rimosse dal frontend: rimane un solo backend applicativo.
- Avvio locale frontend: `npm run dev:frontend` (porta `3100`).
