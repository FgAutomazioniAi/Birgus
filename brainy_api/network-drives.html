Crea un remote ​

POST/brainy/api/filesystem/network/remotesadmin

Crea un connettore a uno storage esterno, testando prima la connessione. Le credenziali sono cifrate. In modalità mappatura selettiva la connessione resta IDLE finché non si aggiungono mount.

Autorizzazione — Solo amministratori. Vedi Autenticazione.

Corpo della richiesta ​

ParametroTipoDescrizione
statebodyda documentare
providerbodyChiave del connettore (una tra Google, Dropbox, OneDrive, Sftp, Samba, Nfs, SharePoint) come da GET /filesystem/network/providers — per l'SMB il valore è Samba, non SMB.
namebodyNome del remote.
parametersbodyCredenziali specifiche del provider (i campi richiesti sono in GET /filesystem/network/providers) — per SFTP/SMB host/user/pass/port/folder (SMB anche domain); per i provider cloud (Google/OneDrive/Dropbox) si usa invece code OAuth2.
codebodyCodice OAuth2 (per i provider cloud, opzionale).
descriptionbodyDescrizione.

Errori ​

CodiceCondizione
400Parameter provider and name are required
406Exists a directory with same name
500Error creating remote: ${error.message}

Esempi ​

Richiesta (SFTP)

bash
curl -s -X POST "$BRAINY_BASE/brainy/api/filesystem/network/remotes" \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"provider":"Sftp","name":"Server FTP","parameters":{"host":"sftp.example","user":"utente","pass":"secret","port":22,"folder":"/"}}'

Richiesta (SMB → provider "Samba")

bash
curl -s -X POST "$BRAINY_BASE/brainy/api/filesystem/network/remotes" \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"provider":"Samba","name":"Server SMB","parameters":{"host":"192.168.1.10","user":"utente","pass":"secret","domain":"WORKGROUP","port":445,"folder":"data/eee"}}'

Aggiorna le credenziali di un remote ​

PUT/brainy/api/filesystem/network/remotesadmin

Aggiorna le credenziali di un remote. Il remote è identificato dall'id nel corpo (non nel path).

Autorizzazione — Solo amministratori. Vedi Autenticazione.

Corpo della richiesta ​

ParametroTipoDescrizione
statebodyda documentare
idbodyID del remote (nel corpo).
providerbodyChiave del connettore (Google/Dropbox/OneDrive/Sftp/Samba/Nfs/SharePoint).
namebodyNome.
parametersbodyNuove credenziali specifiche del provider (vedi GET /filesystem/network/providers).
codebodyCodice OAuth2 (opzionale).

Autorizzazione — Solo amministratori. Vedi Autenticazione.
