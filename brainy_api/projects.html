Elenco progetti ​

GET/brainy/api/projectsautenticato

Lista paginata dei progetti visibili al chiamante nella cartella corrente (con ricerca ricorsiva nelle sottocartelle), con filtri per KPI e nome. Ogni riga include il ruolo effettivo, la visibilità e i conteggi.

Autorizzazione — Autenticato; il perimetro è filtrato dai permessi (ProjectACL). Vedi Autenticazione.

Parametri di query ​

ParametroTipoDescrizione
folder_idqueryCartella di cui elencare i progetti (default radice).
kpiqueryFiltro per stato/KPI (favorite, private, shared, active, archived).
query_namequeryFiltro per sottostringa sul nome (ricerca ricorsiva nella cartella).
order_byqueryOrdinamento (updated, name, created, state).
order_dirqueryDirezione (asc/desc).
load_cursorqueryOffset di paginazione. Default 0.
page_sizequeryVoci per pagina. Default 50.

Esempi ​

Richiesta

bash
curl -s "$BRAINY_BASE/brainy/api/projects?kpi=active" -H "Authorization: Bearer $TOKEN"

Cartella documenti del progetto ​

POST/brainy/api/projects/{id}/fs-folderautenticato

Restituisce la cartella d'archivio in cui finiscono i file caricati dentro un progetto, creandola alla prima richiesta.

Serve prima di un caricamento: senza una destinazione il file finirebbe nella radice dell'archivio, cioè fuori dal progetto. Chi può scrivere nel progetto riceve il permesso di scrittura sulla cartella, così può caricare il file e poi collegarlo.

Autorizzazione — Bearer token (qualsiasi utente autenticato). Vedi Autenticazione.
