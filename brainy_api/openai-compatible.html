Elenca i modelli disponibili ​

GET/brainy/api/openai/v1/modelsservice account

Endpoint OpenAI-compatibile GET /v1/models. Restituisce l'unione dei modelli LLM (dal proxy dei motori di calcolo) e dei modelli audio/STT (se lo stack vocale è attivo). Le due fonti sono indipendenti: se una è irraggiungibile si restituiscono comunque i modelli dell'altra; solo se entrambe sono giù la risposta è 502.

Usalo con qualsiasi SDK OpenAI puntando la base_url a $BRAINY_BASE/brainy/api/openai/v1 e passando il token del service account come API key.

Autorizzazione — Solo account di servizio (token con profilo SERVICE); un utente normale riceve 403. Vedi Autenticazione.

Errori ​

CodiceCondizione
403Forbidden
502Nessun backend modelli raggiungibile (LLM e audio)

Esempi ​

Richiesta

bash
curl -s "$BRAINY_BASE/brainy/api/openai/v1/models" \
  -H "Authorization: Bearer $SERVICE_TOKEN"

Risposta

json
{
  "object": "list",
  "data": [
    { "id": "LLM-Qwen3.5-122B-A10", "object": "model" },
    { "id": "bw-stt", "object": "model", "owned_by": "brainy-gpu" }
  ]
}

Chat completions (OpenAI-compatible) ​

POST/brainy/api/openai/v1/chat/completionsservice account

Endpoint OpenAI-compatibile POST /v1/chat/completions. Inoltra la richiesta al motore LLM configurato e ne restituisce la risposta senza rielaborarla: il corpo è lo standard OpenAI (model, messages, temperature, max_tokens, …).

Con stream: true la risposta è uno stream text/event-stream (Server-Sent Events) di chunk incrementali, esattamente come l'API OpenAI; con stream: false (default) è un singolo JSON chat.completion.

Il valore di model deve essere uno di quelli elencati da GET /v1/models.

Autorizzazione — Solo account di servizio (token con profilo SERVICE); un utente normale riceve 403. Vedi Autenticazione.

Corpo della richiesta ​

ParametroTipoDescrizione
modelbodyNome del modello (uno di quelli da GET /v1/models).
messagesbodyLista di messaggi della conversazione (role + content), formato OpenAI.
streambodySe true, risposta in streaming SSE. Default false.
max_tokensbodyNumero massimo di token generati (opzionale).
temperaturebodyParametro di campionamento, come nell'API OpenAI (opzionale).

Errori ​

CodiceCondizione
403Forbidden

Esempi ​

Richiesta

bash
curl -s "$BRAINY_BASE/brainy/api/openai/v1/chat/completions" \
  -H "Authorization: Bearer $SERVICE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model":"LLM-Qwen3.5-122B-A10","messages":[{"role":"user","content":"Ciao"}],"stream":false}'

Risposta

json
{
  "object": "chat.completion",
  "model": "LLM-Qwen3.5-122B-A10",
  "choices": [
    { "index": 0, "message": { "role": "assistant", "content": "Ciao!" } }
  ]
}

Trascrizione audio (speech-to-text) ​

POST/brainy/api/openai/v1/audio/transcriptionsservice account

Endpoint OpenAI-compatibile POST /v1/audio/transcriptions. Riceve un file audio in multipart/form-data e lo inoltra al motore STT (speech-to-text), restituendone la trascrizione nel formato OpenAI.

Richiede un compute engine di tipo stt abilitato e raggiungibile (il backend speech-to-text, es. NeMo, esposto tramite il gateway dei motori). Se il motore non è configurato o non risponde, la richiesta fallisce a monte.

Autorizzazione — Solo account di servizio (token con profilo SERVICE); un utente normale riceve 403. Vedi Autenticazione.

Corpo della richiesta ​

ParametroTipoDescrizione
filebodyFile audio da trascrivere (campo multipart).
modelbodyModello dell'engine STT (qui bw-stt; campo multipart).

Errori ​

CodiceCondizione
403Forbidden

Esempi ​

Richiesta

bash
curl -s "$BRAINY_BASE/brainy/api/openai/v1/audio/transcriptions" \
  -H "Authorization: Bearer $SERVICE_TOKEN" \
  -F "file=@audio.mp3" \
  -F "model=bw-stt"

Sintesi vocale (text-to-speech) ​

POST/brainy/api/openai/v1/audio/speechservice account

Endpoint OpenAI-compatibile POST /v1/audio/speech. Inoltra al motore TTS (text-to-speech) un corpo JSON in stile OpenAI (model, input, voice, …) e restituisce i byte audio sintetizzati.

Richiede un compute engine di tipo tts abilitato e raggiungibile (il backend text-to-speech, es. Chatterbox, esposto tramite il gateway dei motori). Se il motore non è configurato o non risponde, la richiesta fallisce a monte.

Autorizzazione — Solo account di servizio (token con profilo SERVICE); un utente normale riceve 403. Vedi Autenticazione.

Corpo della richiesta ​

ParametroTipoDescrizione
modelbodyModello dell'engine TTS (qui bw-tts).
inputbodyTesto da sintetizzare.
voicebodyVoce dell'engine (qui voice_01; le voci dipendono dalla config del motore).

Errori ​

CodiceCondizione
403Forbidden

Esempi ​

Richiesta

bash
curl -s "$BRAINY_BASE/brainy/api/openai/v1/audio/speech" \
  -H "Authorization: Bearer $SERVICE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model":"bw-tts","input":"Ciao dal sistema","voice":"voice_01"}' \
  --output speech.mp3
