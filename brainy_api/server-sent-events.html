Server-Sent Events ​

3 endpoint.

Apri il canale SSE ​

GET/brainy/api/sse/connectautenticato

Apre uno stream SSE real-time per l'utente autenticato (aggiornamenti push).

Autorizzazione — Autenticato (header Bearer o cookie di sessione). Vedi Autenticazione.

Apri il canale SSE (token nel path) ​

GET/brainy/api/sse/connect/{auth_token}pubblico

Come /sse/connect, ma il token JWT è passato nel path (per EventSource che non può impostare header). Firma non valida → 401.

Autorizzazione — Il JWT nel path è l'autorizzazione (per client che non possono usare header, es. EventSource). Vedi Autenticazione.

Parametri di path ​

ParametroTipoDescrizione
auth_tokenpathJWT firmato dell'utente.

Client SSE connessi (admin) ​

GET/brainy/api/sse/clientsadmin

Elenco dei client attualmente connessi al canale SSE.

Autorizzazione — Solo amministratori. Vedi Autenticazione.
