Elenco agenti AI ​

GET/brainy/api/ai/agentsautenticato

Lista paginata degli agenti AI visibili al chiamante.

Un admin vede tutti gli agenti dell'organizzazione. Un utente normale vede solo gli agenti su cui ha un permesso — diretto o ereditato da un gruppo — più gli agenti di sistema, sempre visibili a tutti.

Autorizzazione — Autenticato; i non-admin vedono solo gli agenti su cui hanno permesso (ACL) più quelli di sistema. Vedi Autenticazione.

Parametri di query ​

ParametroTipoDescrizione
load_cursorqueryCursore di paginazione, ovvero l'offset del primo record. Default 0.
page_sizequeryNumero di risultati per pagina. Default 100.
preferredquerySe true, restituisce solo gli agenti marcati come preferiti.
namequeryFiltro per sottostringa sul nome dell'agente.
order_byqueryColonna di ordinamento (name, created, …).
order_dirqueryDirezione di ordinamento, asc o desc.
folder_idqueryRestituisce solo gli agenti contenuti nella cartella indicata.
recursivequerySe true, con folder_id include anche gli agenti delle sottocartelle.

Esempi ​

Richiesta

bash
curl -s "$BRAINY_BASE/brainy/api/ai/agents?page_size=2" \
  -H "Authorization: Bearer $TOKEN"

Esegui un agente (streaming) ​

POST/brainy/api/ai/agents/{agent_id}/runautenticato

Esegue l'agente su un messaggio e restituisce la risposta in streamingtext/event-stream (SSE). Se session_id è vuoto crea una nuova sessione.

Supporta allegati, entry del file system, override del modello, ricerca web e reasoning. Eventi SSE: BEGIN, THINKING (fasi RAG), CHUNK (contenuto+reasoning), PROGRESS/RESULT/ERROR, END.

Autorizzazione — Autenticato con permesso di lettura sull'agente (ACL READ). Vedi Autenticazione.

Parametri di path ​

ParametroTipoDescrizione
agent_idpathID dell'agente da eseguire.

Parametri di query ​

ParametroTipoDescrizione
errorquerySolo in sviluppo — inietta un errore di test.

Corpo della richiesta ​

ParametroTipoDescrizione
session_idbodyID della sessione (vuoto = nuova).
session_namebodyNome della sessione (alla creazione).
messagebodyTesto del messaggio dell'utente (obbligatorio).
reasoningbodySe true, abilita il reasoning esteso.
web_searchbodyTri-stato per la ricerca web (null = default dell'agente).
modelbodyNome del modello con cui forzare l'esecuzione (se supportato).
chat_tokenbodyToken di una chat standalone, per abilitare parametri via whitelist.
paramsbodyParametri aggiuntivi passati al flow/agente (sanificati).
file_system_entriesbodyElenco di entry del file system da usare come contesto.
attachment_idsbodyElenco di allegati (id) da iniettare nel contesto.
langfuse_tagsbodyTag Langfuse per la tracciatura (array o stringa CSV).
promptbodyOverride opzionale del prompt di sistema per questa esecuzione.

Esempi ​

Richiesta (SSE)

bash
curl -sN -X POST "$BRAINY_BASE/brainy/api/ai/agents/12/run" \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"message":"Riassumi il documento","session_name":"Chat"}'

Risposta (stream SSE)

text
event: BEGIN
data: {"session_id":"34", ...}

event: CHUNK
data: {"role":"agent","content":"…"}

event: END
data: {"session_id":"34","elapsed_ms":1496}

Imposta la configurazione di pubblicazione ​

POST/brainy/api/ai/agents/{agent_id}/public-tokenautenticato

Abilita/disabilita la pubblicazione dell'agente come widget e ne imposta l'allowlist di domini e il rate-limit. Riabilitando, la publishable key precedente viene riattivata (non rigenerata).

Autorizzazione — Autenticato con permesso di scrittura sull'agente (ACL WRITE). Vedi Autenticazione.

Parametri di path ​

ParametroTipoDescrizione
agent_idpathID dell'agente.

Corpo della richiesta ​

ParametroTipoDescrizione
publicbodySe true, pubblica l'agente come widget.
rate_limitbodyLimite di richieste (minimo 1, default 20).
allowed_originsbodyElenco di Origin ammessi per l'embed.

Errori ​

CodiceCondizione
403Forbidden

Esempi ​

Richiesta

bash
curl -s -X POST "$BRAINY_BASE/brainy/api/ai/agents/12/public-token" \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"public":true,"rate_limit":30,"allowed_origins":["https://sito.example"]}'

Esegui l'agente pubblico (streaming) ​

POST/brainy/api/ai/public/agents/{agent_id}/runpubblico

Esegue l'agente pubblico per un visitatore anonimo e ne trasmette la risposta in SSE. L'autorizzazione è il token visitatore (header Authorization: Bearer); l'identità è il visitor_ray del token (nessun utente → strumenti privilegiati disabilitati, solo RAG). L'agente deve essere pubblico.

Autorizzazione — Pubblico — token visitatore (dal token di sessione) legato all'agente. Vedi Autenticazione.

Parametri di path ​

ParametroTipoDescrizione
agent_idpathID dell'agente pubblico.

Corpo della richiesta ​

ParametroTipoDescrizione
session_idbodyID della conversazione (vuoto = nuova).
messagebodyMessaggio del visitatore (obbligatorio).
session_namebodyNome della conversazione.
chat_tokenbodyToken di una chat standalone, per abilitare parametri via whitelist.
paramsbodyParametri aggiuntivi passati al flow/agente (sanificati).

Risposta in streaming

Questo endpoint risponde con text/event-stream (Server-Sent Events), non con un JSON singolo.

Esempi ​

Richiesta (SSE)

bash
curl -sN -X POST "$BRAINY_BASE/brainy/api/ai/public/agents/12/run" \
  -H "Authorization: Bearer $VISITOR_TOKEN" -H "Content-Type: application/json" \
  -d '{"message":"Ciao"}'

Apri l'editor delle automazioni ​

POST/brainy/api/ai/agents/n8n/sessionautenticato

Prepara la sessione che permette di aprire l'editor delle automazioni già autenticati, senza una seconda schermata di accesso.

Le credenziali dell'editor non passano mai dal browser: restano sul server, che esegue l'accesso per conto dell'utente e restituisce alla pagina soltanto la sessione risultante. Il permesso di entrare è quello di Brainyware — chi non è autenticato sulla piattaforma non ottiene nulla.

Risponde 409 se il motore delle automazioni è disattivato sull'installazione e 503 se l'editor non è raggiungibile.

Autorizzazione — Bearer token (qualsiasi utente autenticato). Vedi Autenticazione.

Errori ​

CodiceCondizione
409n8n engine is disabled
503n8n SSO unavailable: ${Ex?.message || Ex}
