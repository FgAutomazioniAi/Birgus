Avatar ​

17 endpoint.

Config del widget avatar ​

GET/brainy/api/avatar/configpubblico

Configurazione pubblica del widget avatar (branding, timeout, LiveAvatar) letta dall'ambiente. Bootstrap della pagina.

Autorizzazione — Pubblico (aperto, nessun token). Vedi Autenticazione.

Stato del servizio avatar ​

GET/brainy/api/avatarpubblico

Probe di liveness. Restituisce { status: "alive" }.

Autorizzazione — Pubblico (aperto). Vedi Autenticazione.

Conia un token visitatore anonimo ​

POST/brainy/api/avatar/authpubblico

Conia un token JWT anonimo (unlogged_ray) usato da tutte le chiamate avatar successive. Con user_id valorizzato risponde 400 (il login è su altra rotta).

Autorizzazione — Pubblico — endpoint di emissione del token. Vedi Autenticazione.

Corpo della richiesta ​

ParametroTipoDescrizione
user_idbodyDeve essere assente/nullo (il login non è gestito qui).

Carica un file (base64, interno) ​

POST/brainy/api/avatar/upload/base64interno (gateway)

Carica un file in base64 su S3 temporaneo (cancellato dopo 2h) e restituisce un URL firmato. Accessibile solo da loopback.

Autorizzazione — Interno — solo loopback + token avatar; ingest base64 verso S3 temporaneo. Vedi Autenticazione.

Corpo della richiesta ​

ParametroTipoDescrizione
filebodyContenuto in base64.
filenamebodyNome del file.
mime_typebodyMIME type.

Errori ​

CodiceCondizione
400Bad Request
403Forbidden
405Method Not Allowed
413Payload Too Large
